EduMap Africa

Independent EdTech project

Screenshot coming soon — replace this block with an <img> of the live map view

A resource-mapping platform designed to showcase and track educational opportunities — scholarships, tutoring programmes, school resources, and community learning initiatives — across Africa, making it easier for learners and parents to discover what's available near them.

My Approach

  • Identified the core problem: education opportunities exist but are scattered across flyers, social media, and word of mouth, with no central, searchable source.
  • Designed a simple data model for opportunities (location, type, eligibility, deadline) and a front-end interface to browse and filter them.
  • Built the interface mobile-first, since most target users access the internet primarily through phones.

Tools Used

HTML5 CSS3 JavaScript Google Sheets (data source)

Key Lessons Learned

Good data structure matters more than a polished UI in the early stage of a resource platform — I spent more time getting the opportunity data model right than on visuals, and that made every later feature easier to build. I also learned to design for low-bandwidth, mobile-first users rather than assuming a desktop-first audience.

EduChain for SDG4

Academic / hackathon concept project

Screenshot coming soon — replace this block with a diagram of the scholarship flow

A blockchain-based concept solution to bring transparency and equity to scholarship distribution, addressing SDG 4 (Quality Education) by making it possible to trace how scholarship funds move from donor to recipient.

My Approach

  • Researched common failure points in scholarship distribution — funds not reaching intended recipients, unclear eligibility criteria, and lack of donor visibility.
  • Mapped a simple flow where each stage of disbursement (donor → institution → student) is recorded as a transparent, tamper-resistant transaction.
  • Prototyped the concept and data flow, focusing on the logic and trust model rather than a full production blockchain deployment.

Tools Used

Blockchain concepts Process mapping Google Workspace

Key Lessons Learned

Technology alone doesn't solve a trust problem — the hardest part wasn't the blockchain logic, it was designing a process that institutions and donors would actually adopt. This taught me to start every EdTech idea from the human workflow first, then decide what technology actually earns its place in that workflow.

SME & NGO Data Analytics Dashboards

Applied data analytics practice project

Screenshot coming soon — replace this block with a dashboard export

Two linked data analysis projects: a sales dashboard for a local retail shop, and a survey analysis for an NGO's donor reporting — both aimed at helping small organisations make decisions from data they already collect but rarely use.

My Approach

  • For the retail shop: consolidated two years of scattered sales records, cleaned the data, and built a dashboard showing monthly revenue trends, top-selling products, and slow-moving stock.
  • For the NGO: cleaned a 200+ response beneficiary survey export, analysed response patterns by demographic group, and produced a one-page summary report for their donor reporting deadline.
  • In both cases, prioritised clarity for a non-technical audience over analytical complexity — the goal was decisions made, not just charts produced.

Tools Used

Excel Power BI Python (pandas, matplotlib) Google Forms / Sheets

Key Lessons Learned

Real-world data is messy — missing values, inconsistent naming, duplicate entries — and cleaning it well is most of the work. I also learned that a dashboard only creates value if the person reading it can act on it immediately, which pushed me to design for the decision-maker, not for the dataset.
